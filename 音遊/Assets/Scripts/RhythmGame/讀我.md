# 落下式音遊 — 使用說明

把 Python 那邊辨識出來的樂譜變成可以玩的音遊：音符從上往下掉，落到 88 鍵鋼琴上，
按對就得分。

```
data/charts/<曲名>_lv1.json   ← run.py score build 產出的
data/charts/<曲名>_lv2.json
        │
        ▼
   音符從上往下掉  →  落到琴鍵上  →  按鍵判定  →  連擊與分數
```

---

## 怎麼開始

打開 `Assets/Scenes/SampleScene`，按 **Play**。元件已經掛好了。

（另外開新場景的話：**Tools → 鋼琴 UI → 建立落下式音遊到場景**）

按 Play 會先出現**選曲畫面**，列出 `data/charts/` 裡所有的譜。
沒有譜面的話畫面會直接告訴你要去 Python 那邊執行 `run.py score build <專案名>`。

### 不會彈也能看

按 **F1** 開自動演奏，電腦會自己照著譜彈給你看。這也是確認譜面對不對最快的方式 ——
如果自動演奏出現 Miss，那就是譜面資料或判定有問題，不是你手殘。

---

## 加入新曲子（全部在遊戲裡完成）

選曲畫面下面有兩個按鈕：

1. 點 **「加入新樂譜（拍照 / 記譜）」** —— 會打開樂譜輸入的網頁介面
2. 在網頁上傳拍好的樂譜照片，或數字/字母記譜的 `.txt`，按「開始辨識」
3. 回到遊戲，點 **「重新掃描」** —— 新曲子就出現在清單裡了

**不用重開 Unity，也不用碰 Inspector。** 譜面是執行時從硬碟掃出來的。

> 辨識樂譜是 Python 那邊做的（homr OMR + 記譜解析），Unity 只負責把那個工具叫起來。
> 「加入新樂譜」按鈕實際上就是去執行專案根目錄的 `加樂譜.bat`。

一首曲子如果左右手都有，會出現**兩個項目**：難度 1（只有右手）和難度 2（雙手）。
只寫了右手的記譜檔就只會有一個。

### 選曲畫面的操作

**用滑鼠點一首就開始。** 鍵盤只是快捷鍵：

| 按鍵 | 作用 |
|---|---|
| `↑` `↓` | 選擇 |
| `Enter` | 開始 |
| `F5` | 重新掃描譜面資料夾 |
| `Esc` | 回到遊戲（已經有曲子在跑時） |

> 選曲畫面刻意做成**滑鼠也能操作**。Unity 的 Game 視窗如果沒有被點過就沒有鍵盤焦點，
> 只做鍵盤操作的話會出現「畫面在那裡但按什麼都沒反應」的死結。

遊戲中按 **Esc** 會先叫出暫停選單，在那裡選「回到選曲」才會換曲子。

---

## 操作

| 按鍵 | 作用 |
|---|---|
| 滑鼠點琴鍵 | 彈那個音（按著橫掃可以滑奏） |
| `A W S E D F T G Y H U J K O L P` | 電腦鍵盤彈琴，A 對應中央 C |
| **`Space`** | **延音踏板**（也可以用滑鼠點畫面左下角的踏板） |
| `P` | 暫停 / 繼續（不跳選單） |
| `R` | 重來 |
| `F1` | 自動演奏開關 |
| `Esc` | **暫停選單** |

---

## 暫停選單

彈奏中按 **Esc**，畫面會半透明壓暗停在原地 —— 刻意留著後面看得到，
才是「暫停」而不是換頁。

| 按鍵 | 作用 |
|---|---|
| `Esc` | 繼續（**先倒數三秒**） |
| `R` | 重來（整首，不是上次練的那一段） |
| `Q` | 回到選曲 |

三顆按鈕滑鼠也能點。倒數是必要的：暫停時手已經離開琴鍵，
直接接下去的話最前面那幾顆一定來不及按，會憑空多幾個 Miss。

> 倒數用 `Time.deltaTime`，跟 `RhythmGameController` 的 `SongTime` 同一個時鐘。
> 暫停是靠「不累加 SongTime」做的，全專案沒有動過 `timeScale`。
> 如果哪天有人改成 `timeScale = 0` 暫停，這個倒數會卡住不動。

## 彈完後的檢討

一首彈完會自動跳出**檢討畫面**：

- 統計每一小節有幾顆音沒打好，把相鄰的弱小節併成段落
- 直接在**你自己拍的樂譜照片**上把那幾小節圈紅，其餘壓暗
- 只裁出有問題的那幾行放大顯示 —— 整頁 A4 塞進畫面會小到看不清楚

| 按鍵 | 作用 |
|---|---|
| `R` | **只重練這一段**（只播那幾小節，不用從頭） |
| `Tab` | 看下一段（找出多段時） |
| `Esc` | 回到選曲 |

判定標準在 Inspector 的 `ReviewScreen`：
`Weak Ratio`（一小節多少比例沒打好才算弱，預設 0.25）、
`Merge Gap`（相鄰弱小節隔幾小節以內就併起來）、`Max Sections`（最多列幾段）。

> 樂譜照片的小節位置是 Python 那邊算好寫進 chart JSON 的
> （`src/score_input/layout.py` 偵測小節線）。文字記譜沒有照片，
> 那就只顯示文字，不畫圖。

## 長音與延音踏板

**長音（0.35 秒以上）要按住才算完整**，不是按一下就好。

| 情況 | 結果 |
|---|---|
| 按住到音符結束（提早 0.15 秒內放開也算） | 維持按下時的成績 |
| 只按住 60% 以上就放開 | 成績降一級（Perfect → Great） |
| 按不到 60% 就放開 | Miss |

**踩著延音踏板的時候，放開琴鍵不算中斷** —— 跟真鋼琴一樣，踏板踩著時制音器
整排抬起來，手指離鍵音還是繼續響。所以長音接不順的時候可以用踏板。

踏板同時也會讓聲音延續得更久（音長 ×2.6、衰減 ×0.35）。

> 之後接上電子琴的實體踏板（MIDI CC64）就呼叫 `SustainPedal.SetPressed()`，
> 它跟鍵盤、滑鼠是並存的三個來源，不會互相覆寫。
> 評分那一側早就在看這個：`src/io_utils.py` 的 `extract_pedal()` 會抽 CC64 事件，
> `src/scoring.py` 有獨立的踏板維度。

## Inspector 參數

全部在 `RhythmGameController` 上。

### 譜面

| 參數 | 說明 |
|---|---|
| **Chart Folder** | 譜面資料夾。預設 `../../data/charts` 會指到專案根目錄，也就是 `run.py score build` 的輸出位置，開發時不用複製檔案 |
| **Chart File** | 開場預設選中哪一首。**平常不用改，用遊戲裡的選曲畫面就好**；留空就用資料夾裡的第一個 |

### 玩法

| 參數 | 預設 | 說明 |
|---|---|---|
| **Approach Seconds** | 2.0 | 音符從出現到落到判定線要幾秒。**越小越難** |
| **Lead In Seconds** | 3.0 | 開始前的倒數，讓第一顆音符有時間落下來 |
| **Auto Play** | 關 | 電腦自己彈 |
| **Play Sound** | 開 | 按鍵發出鋼琴聲（程式合成的，不需要音訊檔） |

### 判定寬容度（秒）

| 參數 | 預設 |
|---|---|
| Perfect Window | 0.05 |
| Great Window | 0.10 |
| Good Window | 0.16 |

超過 Good Window 沒按就算 Miss。覺得太難就把這三個值調大。

### 外觀

| 參數 | 說明 |
|---|---|
| Right / Left Hand Color | 右手藍、左手橘 |
| Note Width Ratio | 音符寬度佔琴鍵寬的比例 |
| Highway Height | 落下區域的高度（像素） |
| Show Hit Line | 畫出判定線（琴鍵上緣的紅線） |

---

## 計分

| 判定 | 基礎分 |
|---|---|
| Perfect | 100 |
| Great | 70 |
| Good | 40 |
| Miss | 0，連擊歸零 |

連擊每 10 下加一倍，最多 8 倍。準確率的算法是 Perfect 算滿分、Great 0.7、Good 0.4。

## 檔案

| 檔案 | 職責 |
|---|---|
| `ChartData.cs` | 譜面 JSON 的資料模型與載入 |
| `FallingNote.cs` | 單一個落下的音符 |
| `RhythmGameController.cs` | 主控：生成、落下、判定、計分、自動演奏 |
| `RhythmGameHUD.cs` | 畫面資訊：曲名、分數、連擊、判定文字、進度條、結算 |
| `PianoAudio.cs` | 程式合成的鋼琴音色（不需要音訊檔） |
| `Editor/RhythmGameMenu.cs` | Tools 選單 |
| `Editor/RhythmGameSelfTest.cs` | 自我檢查，不用按 Play 就能驗譜面資料 |

跟 `PianoUI/` 一樣**全部程式產生**，不需要任何 prefab、美術或音訊資源。

## 出問題的時候

**畫面說找不到譜面**
先去 Python 那邊產生：
```powershell
run.py score new <名稱> --type photo
run.py score add <名稱> <照片或記譜檔>
run.py score build <名稱>
```

**想確認譜面資料對不對**
Tools → 鋼琴 UI → **自我檢查（譜面與資料）**。它會檢查每份譜面的音符數、時間是否
遞增、音高是否在鋼琴範圍內、難度 1 是不是難度 2 的子集，全部印在 Console。
不用按 Play。

**有些音沒出現**
譜面的音超出鍵盤音域了。把 `PianoKeyboardUI` 的「音域」改成 **全部88鍵**。
Console 會有警告說明少了幾個音。

**JsonUtility 讀成 0**
如果分數永遠是 0、音符全部擠在一起，多半是譜面 JSON 的欄位名稱跟 `ChartData.cs`
對不上。JsonUtility 是靠**名字**對應的，對不上不會報錯只會給 0。
自我檢查會抓到這種情況。
