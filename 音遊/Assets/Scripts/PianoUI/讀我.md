# 鋼琴鍵盤 UI — 使用說明

按下琴鍵，角色**瞬移**到那顆鍵的正上方。整個 UI 是執行時用程式生的，
不需要任何美術資源，也不用手動拉 Canvas 或排琴鍵。

---

## 怎麼跑起來

1. 回到 Unity，等它自動編譯完（右下角轉圈圈停止）
2. 上方選單 **Tools → 鋼琴 UI → 建立鍵盤到場景**
3. 按 **Play**

就會看到兩個八度的鍵盤和一個橘色角色。

> 也可以自己來：建一個空物件 → Add Component → `Piano Keyboard UI`。

---

## 怎麼玩

| 操作 | 說明 |
|---|---|
| 滑鼠點琴鍵 | 角色瞬移到該鍵上 |
| 按著滑鼠橫掃 | 滑奏（glissando），角色會一路跟著跳 |
| 電腦鍵盤 | `A W S E D F T G Y H U J K O L P` ← 排列和真的鍵盤一樣，`A` 預設 = 中央 C |

> 電腦鍵盤的起點是 `Computer Keyboard Start Midi`（預設 60 = 中央 C），
> 和音域起點分開設定 —— 88 鍵時音域從 A0 開始，但電腦鍵盤當然要落在中音區才好彈。

---

## Inspector 可以調什麼

選到 `PianoKeyboard` 物件，`Piano Keyboard UI` 元件上：

**音域**
- `Range` — 預設 **全部88鍵**（A0–C8）。另有 76 / 61 / 49 鍵，或選「自訂」再自己填
  `Start Midi` 和 `White Key Count`
- 琴的鍵數比畫面少沒關係，用不到的鍵只是不會亮

| 選項 | 音域 | 白鍵數 |
|---|---|---|
| 全部88鍵 | A0 – C8 | 52 |
| 鍵76 | E1 – G7 | 45 |
| 鍵61 | C2 – C7 | 36 |
| 鍵49 | C2 – C6 | 29 |

**尺寸**
- `Auto Fit Width` — **88 鍵一定要開**，會自動把鍵寬算成剛好撐滿畫面
  （1920 寬時白鍵約 36px、黑鍵約 21px）
- `Black Key Width / Height Ratio` — 黑鍵佔白鍵的比例，預設 0.58 / 0.63，接近真鋼琴
- `Draw Background` — 關掉就變透明，之後要疊在遊戲畫面上就關這個

**和弦**
- `Chord Policy` — 預設 **最高音**：同時按多個音時角色站最高的那顆（旋律線）。
  放開最高音後會退回剩下還按著的最高音；全部放開則留在原地。
  另一個選項是「最後按的」

**角色**
- `Character Sprite` — 留空就用程式畫的圓形角色（附兩顆眼睛）。
  之後有自己的角色圖，拉進來就換掉了
- `Auto Scale Character` — 角色大小跟著鍵寬縮放，88 鍵時要開
- `Character Width Ratio` — 角色寬 = 白鍵寬 × 這個值，預設 1.5。
  88 鍵時角色一定會比單一鍵寬（54px vs 36px），覺得擋到就調小
- `Character Color`

`Character` 子物件上還有 `Character Hopper`，可以調落地表現：
- `Squash On Land` — 關掉就是**完全沒有動畫的純瞬移**
- `Black Key Lift` — 站黑鍵時額外墊高幾像素，表現黑鍵比較高
- `Show Landing Ring` — 落地的擴散光圈

## 之後要接東西的話

`PianoKeyboardUI` 已經留好接口，不用改內部程式：

```csharp
// 用 MIDI 音高觸發，角色一樣會瞬移過去
keyboard.PressNote(60);    // 中央 C
keyboard.ReleaseNote(60);

// 訂閱事件，接你的判定 / 計分邏輯
keyboard.NotePressed += midi => Debug.Log($"彈了 {midi}");
keyboard.NoteReleased += midi => { };

keyboard.GetKey(60);       // 拿到那顆鍵，可以自己改顏色做提示
```

要接上層專案的電子琴（`run.py` 那套 USB-MIDI），
之後寫一個橋接把收到的 note number 丟進 `PressNote()` 就好。

## 檔案

| 檔案 | 做什麼 |
|---|---|
| `PianoKeyboardUI.cs` | 主體。生 Canvas / 琴鍵 / 角色，處理輸入，對外事件 |
| `PianoKey.cs` | 單顆琴鍵。外觀、按下放開、滑鼠事件 |
| `CharacterHopper.cs` | 角色。`TeleportTo()` 就是瞬移那一行 |
| `UIShapes.cs` | 程式畫的圓角矩形和圓形，所以不需要圖檔 |
| `Editor/PianoKeyboardMenu.cs` | Tools 選單 |

---

## 備註

- 專案的 Input Handling 是 **Both**，腳本走舊版 `Input` 分支；
  之後若改成只用 New Input System，腳本頂端的條件編譯會自動切過去，不用改東西。
- 琴鍵是 uGUI 的 `Image`，走 Canvas，和專案的 URP 2D 不衝突。
